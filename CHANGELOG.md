# Changelog

All notable changes to GOODS-DRAGON will be documented in this file.

## [2.0.0] - 2024-08-06

### Added
- Professional CLI mode (no GUI menu)
- `--color` flag (auto/always/never) for terminal output
- Progress bar and hacker UI animations
- Sound alerts on scan completion
- HTML, Markdown, TXT, and PDF report generation
- Web UI (Flask Dashboard) on localhost:5000
- Dependency checker and auto-installer
- Self-updater from official GitHub repository
- Professional badges in README (Stars, Forks, License, Version, Team)
- `pyproject.toml` ready for PyPI publishing
- GitHub Actions CI/CD workflow
- CHANGELOG.md file

### Changed
- Renamed from Dragon Eye to GOODS-DRAGON
- Username updated to 0xL-DRAGON
- Team name: L-DRAGON
- License updated to GPL v3
- All source files cleaned and formatted with Black + isort

### Removed
- Interactive GUI menu (replaced by CLI help)
- Old backup files (.bak, .save, .asc)
- Sensitive scan reports from public repository
- Persian text (fully English now)
