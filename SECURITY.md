# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GOODS-DRAGON, please report it responsibly.

**Do not open a public issue.**

Instead, email us at:
- **l.dragon.support@gmail.com**

Please include:
- A detailed description of the vulnerability
- Steps to reproduce it
- Your suggested fix (if any)

We will respond within 48 hours and work with you to resolve the issue quickly.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.0   | ✅ Yes    |

## Security Best Practices

- Always download GOODS-DRAGON from the [official repository](https://github.com/0xL-DRAGON/GOODS-DRAGON)
- Verify the integrity of downloaded files
- Keep your Python environment updated
- Use virtual environments for isolation
